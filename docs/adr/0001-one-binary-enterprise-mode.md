# ADR-0001 同一个安装包，按企业配置切换企业模式

状态：已采纳（0.7–1.0）

## 背景

企业需要统一管理，个人用户需要什么都不变。两套安装包意味着两条更新链路、两套签名和发布，而且个人用户升级时可能误装企业版。

## 决定

只发一个安装包。系统目录里有 `enrollment.json` 或 `managed.json` 时进入企业模式，否则就是个人模式，代码路径完全不受影响（`enterprise/controller.ts` 在个人模式下所有方法都不起作用）。

企业模式下：
- 运行时固定用内置 DSH，数据放在 `<客户端目录>/enterprise/dsh`，不碰个人的 `~/.dsh`；
- 连接方式、运行时来源、数据环境不能修改；
- 配置文件存在但内容无效时**拒绝启动**，不回退到个人模式。

## 放弃的方案

- **单独的 Pro 安装包**：维护成本翻倍，自动更新容易混乱。
- **企业模式共用 `~/.dsh`**：组织凭据会和个人数据混在一起，退出企业时没法干净清理。
- **配置无效时回退个人模式**：员工会在没有任何管控的情况下继续用，这正是 IT 最不想看到的。

## 修订

- 0.7.0-beta.4：系统目录里什么都没有时，员工可以在桌面设置里自己加入组织，登记写在客户端自己的目录里，见 [ADR-0009](0009-join-from-settings.md)。系统目录里的配置仍然优先。
