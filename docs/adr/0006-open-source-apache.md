# ADR-0006 全部开源，Apache-2.0，不做商业版

状态：已采纳（0.6.0 起）

## 决定

整个仓库（客户端、协议、服务端、控制台）都按 Apache-2.0 授权，没有 `ee/` 目录，没有 License 证书，也不限用户数。贡献需要 DCO（`Signed-off-by`），不需要 CLA。0.5.29 及更早的版本仍按 MIT 授权。

## 理由

- 企业愿意部署一个管控平台，前提是能审计它的代码，完全开源能直接打消安全顾虑。
- 现在复刻一个闭源实现的成本很低，闭源挡不住竞争，只会挡住信任。
- 选 Apache-2.0 而不是 MIT：多了明确的专利授权条款，改动文件需要标注修改，这两点企业法务审查时都看重。

## 放弃的方案

- **Dify / FastGPT 式附加条款**（禁止多租户 SaaS、保留 Logo）：不属于 OSI 认可的开源协议，和「完全开源」相矛盾。
- **open core（`ee/` + License + 席位）**：源码公开时，License 校验只是法律约束，挡不住删校验的人，却让真心想用的企业多一道审批。

## 补充：付费支持（见 ADR-0007）

「不做商业版」指的是代码和功能：没有闭源模块、没有 License 校验、没有按人数收费的功能。付费支持卖的是时间和承诺（部署协助、升级与安全响应时限、定制集成），不卖代码，与本决定不冲突。
