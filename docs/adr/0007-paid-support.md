# ADR-0007 可持续方式：付费支持

状态：已采纳（2026-11-16）

## 背景

管理服务端是安全产品：企业部署之后，会期待安全问题有人响应、升级有人保证、出了问题有人排查。这些是持续的义务，目前只有一位维护者。ADR-0006 决定代码全部开源、不做商业版，需要另一种方式支撑这些义务。

## 决定

提供付费支持，代码和功能保持全部开源（Apache-2.0），所有人拿到的是同一份代码。

付费支持的内容是服务，不是功能：

- 部署与接入协助（IdP、网关、MDM 分发）；
- 安全问题和故障的响应时限；
- 升级与数据迁移的协助和保证；
- 按需的定制集成（例如特定 IdP 或内部系统）。

具体的价格、渠道和响应时限尚未确定，在确定之前，README 和文档里不写承诺。

## 放弃的方案

- **open core / 企业版**：见 ADR-0006。
- **托管服务（SaaS）**：要替客户保管模型 Key 和审计数据，责任和合规成本远超一个人的能力，也违背「数据留在企业自己手里」的定位。
- **纯社区、不收费**：无法承诺响应时限，企业很难把它用在正式环境。
